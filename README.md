# PrepPilot

AI-powered Interview Preparation Platform built using Spring Boot, Spring AI, React, PostgreSQL, and PGVector.

## Features

- User Authentication (JWT)
- Resume Analyzer
- AI Chat Assistant
- PDF Upload & Processing
- RAG-based Question Answering
- Quiz Generator
- Study Plan Generator
- Flashcards
- Bookmarks
- Analytics Dashboard

## Tech Stack

### Backend
- Java 21
- Spring Boot
- Spring Security
- Spring AI
- Spring Data JPA
- Maven

### Frontend
- React
- Material UI
- Axios

### Database
- PostgreSQL
- PGVector

### DevOps

- Git
- GitHub
